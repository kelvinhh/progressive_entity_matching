## 本阶段采用的方案

围绕导读第 8 节提出的可控范围：**固定候选集和权重，比较四种调度策略的早期召回**。
首版实现 Join 路线子集：字符 n-gram、TF-IDF、cosine、top-k，覆盖跨表匹配和单表去重。
调度实现依据原论文第 6 节（PDF 第 13 页），不调用作者算法。

已实现：

- 明确选择文本列的 CSV 输入，隔离 ID 与标签，检查重复 ID 和未知标签。
- 稀疏倒排索引候选生成；支持索引左表、右表或双向合并。
- EC、BFS、DFS、Hybrid，以及去重、稳定排序、预算限制。
- 候选召回率、Recall@B、progressive recall、多预算 CSV、逐对核验顺序。
- 实验配置快照、输入和源码 SHA-256、环境、耗时、整次运行的 Python 内存峰值。
- 手算案例、稀疏/穷举结果对照、随机图预算前缀测试，以及两种任务的端到端测试。

尚未完成的正式复现实验：

1. 取得并确认 2–3 个真实标注数据集，至少覆盖跨表匹配与单表去重；记录来源和使用条款。
2. 固定数据预处理及参数，在真实数据上检查候选召回率，再比较调度；不能按各策略分别修改候选集。
3. 加入字符 3/5-gram、k=1/5/10、索引方向等参数组合；分开报告固定参数对比和调优结果。
4. 重复计时、隔离进程测量 RSS、绘制正式结果图；与原文对比时注明所有设置差异。
5. 核对作者评估工具的 AUC 离散积分和候选耗尽约定，再做数值对照。

预算感知调度、自动选择策略属于导读的扩展建议，首版没有将它们作为论文原算法实现。
组员姓名、实际分工、真实数据集选择和课程截止日期仍未在这些材料中确认。

## 实现约定及与原文的差异

| 项目 | 当前实现 |
| --- | --- |
| 文本 | 指定属性值拼接；Unicode NFKC、casefold、压缩空白；不使用列名、ID、标签 |
| TF-IDF | 跨表时联合两表拟合；单表时拟合一次。idf=log((1+N)/(1+df))+1，计数乘 IDF 后 L2 归一化；这是明确选择的平滑变体 |
| 候选 | 只返回有正相似度的 top-k，不用零分边补齐；相似度相同按字符串 ID 排序 |
| 单表候选 | 每条记录先取 k 个非自身邻居，再规范化无向边并求并集；最终节点度数可以大于 k |
| 跨表调度 | 默认只对左侧节点按邻域平均权重排序；可配置为右侧。不同表相同 ID 是不同节点 |
| 单表调度 | 两端都建邻域；重复邻接项占本地轮次位置，但只在第一次出现时输出和计入预算 |
| BFS | 每轮按节点顺序取邻域的下一个位置；不等同于普通图 BFS |
| Hybrid | 每个节点先取最优边，全局按边权排序；之后按节点平均权重依次输出剩余邻域 |
| EC | 为实现清晰采用全量排序，未采用仅保存预算内边的堆优化 |
| 核验 | 真实标签模拟完美核验器；不训练实际匹配模型 |
| PR@B | 明确采用 sum(R(b), b=1..B)/B；候选耗尽后召回保持不变。B=0 返回 0；并未宣称与作者工具逐位相同 |
| 时间 | 所有策略共享候选生成时间；调度在最大预算处计时一次并在多预算行中标注；核验耗时不计入算法时间 |
| 内存 | tracemalloc 记录整次运行的 Python 分配峰值，包括评估和结果行；不是单算法 RSS，不能据此声称内存优于原论文 |
| 当前数据 | 自编商品记录，仅验证流程；不作为真实数据上的复现结论 |

召回率始终以**全部真实匹配数**为分母，未进入候选集的真匹配仍计为漏检。
若预算超过候选数量，指标中同时记录实际比较数，曲线文件仅列实际比较位置。

## 对导读的补充

导读将四种调度作了直观概括。实现时必须再区分两点：

- 跨表任务只调度一个分区即可，不需要把左右表节点混在同一排名中。
- Hybrid 的第一阶段是将各节点的最优边**全局按边权排序**，与按节点均值顺序输出的 BFS 第一轮可能不同。

参考：Maciejewski et al. (2025), DOI 10.1145/3709715，§§3、5.2、6、7.1。
