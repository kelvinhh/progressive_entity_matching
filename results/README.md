# Results

Commands in the root README write regenerable runs into `outputs/` (Git ignored).
Each run contains `metrics.csv`, `curves.csv`, `orders.csv`, `config.json`, and
`metadata.json`. Use separate output directories for different configurations.

Only curated results generated by this implementation belong here. The imported
authors' CSV and figures stay in the local reference archive.

- [First real-data baseline](first_real_data_baseline.md): setup, measured comparisons, and limitations.
- [All ten-budget metrics](fixed_baseline_metrics.csv): 120 rows across three datasets and four strategies.
- [Run metadata](fixed_baseline_metadata/): input/source hashes and software environment.
- [Reference verification](reference_verification.json): 40 AUC checks plus the scheduling fixture.

Additional completed outputs:

- [Stage-two analysis](stage2_analysis.md): all-grid sensitivity, diagnostic cases, measured resources, and limitations.
- [Parameter sweep](sweep_metrics.csv): 1,680 metric rows from 42 settings, with [provenance](sweep_manifest.json).
- [Resource trials](resource_measurements.csv): 75 measured fresh-process jobs, plus [summary](resource_summary.csv) and [protocol/environment](resource_manifest.json).
- [Figures](figures/): four plots, each exported to PNG, SVG, and PDF; [plotting metadata](figures/metadata.json) records software and input hashes.
- [Fresh-environment check](reproduction_verification.json): baseline quality reproduction using cached pinned data, with explicit verification limits.
- [Full fresh-environment check](full_reproduction_verification.json): complete 1,680-row grid reproduction and 75 resource jobs with matching signatures; timing/RSS values are not expected to match exactly.
- [Course technical report](../report/DSC5003-report.pdf): the measured results and their limitations assembled into the course report structure.

Cora remains a documented mirror variant. Grid settings are descriptive sensitivity
conditions, not independent statistical replicates. No direct numerical reproduction
of the full paper or performance advantage over its implementation is claimed.
