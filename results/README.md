# Results

Commands in the root README write regenerable runs into `outputs/` (Git ignored).
Each run contains `metrics.csv`, `curves.csv`, `orders.csv`, `config.json`, and
`metadata.json`. Use separate output directories for different configurations.

Only curated results generated by this implementation belong here. The imported
authors' CSV and figures stay in the local reference archive. No real benchmark
replication results have been produced yet.
